# Foundation of Embodied AI

[简体中文](README.zh-CN.md) | **English**

Chinese and English learning materials for a future Foundation of Embodied AI course, based on our project experience and generated with the assistance of ChatGPT.

**How to read:** Follow tools → calibration/deep learning → physics/perception/control → reinforcement learning → demonstrations/generative policies → communication/deployment → systems integration. Git and ROS 2 are optional tool references. See the [course map](syllabus/COURSE_MAP_EN.md) · <a href="https://zengxiong111.github.io/zengxiong.github.io/files/COURSE_MAP_EN.pdf" target="_blank">PDF</a>.

## Course materials

20 topics, 40 Markdown files and 40 PDFs. Use the links below to read or download. All PDFs use a shared academic layout; the first chapter starts on page 2. Covers robot dynamics, modern simulation stacks, neural networks and vision Transformers, VLA imitation learning, FQI/SAC, and Dream-1 zero-shot embodiment transfer.
