## 1. 先看任务：机器人究竟需要哪一种视觉输出？

视觉模型不是一个可以任意互换的“感知黑盒”。选择模型前，应先确定**机器人下一步需要的变量**，而不是先比较网络大小或排行榜成绩。

| 任务类型 | 典型输出 | 能解决的问题 | 不能直接得到什么 |
|:--|:--|:--|:--|
| 检测（Detection） | 目标类别、边界框、置信分数 | “目标在哪个区域？” | 精确轮廓、三维距离 |
| 实例分割与跟踪（Segmentation / Tracking） | 像素 Mask、实例 ID、跨帧对应 | “哪些像素属于这把工具？” | 物体深度、刚体 6D 位姿 |
| 深度估计（Depth） | 深度图或双目视差 | “目标表面距离相机多远？” | 物体完整形状、物体坐标系 |
| 三维重建（3D Reconstruction） | 估计网格、形状或纹理 | “物体大致长什么样？” | 必然精确的尺寸、可抓取性 |
| 6D 位姿估计（6D Pose） | 物体三维平移与三维旋转 | “工具相对于相机朝向如何？” | 接触力、摩擦、抓稳与否 |

**最重要的四个区分：** Mask 不是深度；深度图不是完整三维模型；三维模型不是当前位姿；6D 位姿也不是接触状态。一个输出不能替代另一个输出。

**先问四件事：** 只需找到目标，还是必须知道朝向？有没有 RGB-D 或标定双目？有没有 CAD 或参考图像？结果需要离线处理还是进入实时控制环？

## 2. 认识与区分最常用的视觉基础模型

### 2.1 一张表掌握核心模型

| 模型 | 输入条件 | 主要输出 | 最适合的用途 / 关键边界 |
|:--|:--|:--|:--|
| **SAM 2** | 图像或视频；点、框、Mask 提示 | 实例 Mask 与跨帧传播 | **已知目标的分割和视频追踪**；不输出 6D 位姿。 |
| **SAM 3 / 3.1** | 图像或视频；文本概念、视觉示例或视觉提示 | 开放词汇检测、Mask、视频跟踪 | **按语言寻找目标并保持实例**；3.1 改进多目标视频效率，不等于所有设备均能实时。 |
| **FoundationStereo** | 标定、同步、极线校正的左右目图像 | 稠密视差，可换算尺度深度 | **有真实双目时估计距离**；不是单目深度或物体姿态估计器。 |
| **Fast-FoundationStereo** | 与 FoundationStereo 相同 | 更低延迟的双目视差 | **对实时性敏感的双目系统**；需按部署 GPU、分辨率实测。 |
| **FoundationPose** | 通常需要 RGB-D、目标 Mask，以及 CAD 或少量参考图像 | 刚体物体 6D 位姿与跟踪 | **工具与刚体的姿态初始化/更新**；依赖几何先验与观测质量。 |
| **SAM 3D Objects** | 单幅图像中的目标区域 | 候选三维形状、外观及场景布局 | **无 CAD 时生成形状先验**；生成网格不等于经过标定的工程 CAD。 |
| **SAM 3D Body** | 人体图像，可选关键点/Mask 等提示 | 人体三维网格、姿态 | **人体动作与形状理解**；不能直接推断手—物接触力。 |

### 2.2 三组最容易混淆的概念

**SAM 2 与 SAM 3：一个偏“追踪已知实例”，一个兼具“根据概念寻找实例”。** 目标已由点击或框选指定，SAM 2 就能传播 Mask；任务指令是“找到所有红色螺丝刀”，优先考虑 SAM 3 的文本/示例提示。SAM 3.1 主要改善视频多实例推理效率。复杂长指令仍可能需要 VLM/Agent 先把任务拆成可定位的短概念。

**FoundationStereo 与单目深度：几何尺度来源不同。** FoundationStereo 使用经过标定的**真实双目**来预测视差，并结合相机参数恢复尺度深度。单目模型（例如 Depth Anything 3 的相应变体）可从一张图估计深度或多视图几何，但应区分相对深度与专门训练的度量深度版本；不能默认任意模型输出都具有机械臂操作所需的尺度精度。头部相机与不断移动的腕部相机，不能未经外参、同步和立体校正便当作固定左右目。

**FoundationPose 与 SAM 3D Objects：一个估计“现在在哪里”，一个估计“大致长什么样”。** FoundationPose 使用 CAD 或参考图像提供物体先验，再根据当前图像估计/追踪刚体姿态。SAM 3D Objects 可以在缺少 CAD 时给出候选形状，但必须另外检查真实尺寸、坐标定义、网格质量与可观测性，不能直接把生成结果当作精密装配模型。

### 2.3 两类常见补充工具

- **Grounding DINO：** 文本条件的开放词汇目标检测，主要输出边界框；如果只需按语言找框，或希望搭配独立分割器，可考虑它。与 SAM 3 直接输出 Mask 的接口不同。
- **Depth Anything 3：** 覆盖单目与多视图深度/几何任务；选择具体 checkpoint 时需核实是相对深度、度量深度还是多视图几何。可作为无硬件深度时的几何先验，但不可默认替代高精度标定 RGB-D。

## 3. 根据机器人任务选型与组合

### 3.1 一个简洁的选型顺序

**第一步：先确定最低必要输出。** 只需要“找到/持续跟踪目标”时，停在检测或 Mask；需要距离再引入深度；确实需要工具朝向、插装对齐等任务时再加入 6D 位姿。直接视觉策略（VLA）也可能从 RGB 与本体状态直接生成动作，并非必须显式计算位姿。

**第二步：检查传感器和先验。** 已有可靠 RGB-D 时，优先使用其经过对齐和检验的深度；有标定同步双目时，可以选择 FoundationStereo / Fast-FoundationStereo；只有单目时可选深度先验，但谨慎处理尺度。有 CAD 时优先使用 CAD；没有时考虑多视图参考图像或 SAM 3D Objects 作为候选几何来源。

**第三步：按所需输出搭建最小流水线。** 不要让每帧都串行运行所有大模型：文本定位可以只在初始化和丢失重定位时执行，连续帧可交给轻量跟踪和位姿更新。

### 3.2 两条最有代表性的机器人视觉路线

**路线 A：显式几何状态（工具抓取、定向、装配）。**

> 语言目标 → **SAM 3** 定位/分割 → **Mask + RGB-D 深度 + CAD/参考图像** → **FoundationPose** 初始化并跟踪 6D 位姿 → 将位姿交给机器人控制器；丢失时重新定位。

这条路线适合需要目标坐标系、姿态误差或可解释几何约束的操作。**SAM 3 本身不输出物体 6D 位姿；FoundationPose 也不会凭空提供 CAD 或有效深度。**

**路线 B：直接视觉策略（VLA / 视觉闭环操作）。**

> 任务语言 + 相机图像 + 机器人本体状态 → **VLA / 视觉策略** → 机器人动作；必要时使用 **SAM 3、跟踪器或几何估计器** 提供目标监测、状态检查与失败恢复。

这条路线不必强制插入 FoundationPose；需要显式位姿时才额外估计。两条路线可以混合：用显式几何辅助安全检查，而不改变策略的主要输入。

### 3.3 四个典型场景

| 具体问题 | 推荐的最小方案 | 什么时候需要升级 |
|:--|:--|:--|
| 根据语言找到桌上的红色螺丝刀 | SAM 3 找目标并输出 Mask；视频中持续跟踪 | 需要抓取方向时，加入深度和姿态估计。 |
| 从任意方向拿起工具并旋转到指定姿态 | RGB-D + 目标 Mask + CAD/参考图像 + FoundationPose | 遮挡或物体掉落时，触发重定位；接触环节仍需其他反馈。 |
| 没有 CAD，想先获得未知物体的粗略形状 | SAM 3D Objects 生成候选网格 | 精密操作前核验尺度、形状与局部几何；必要时重建或扫描。 |
| 仅有单目 RGB，想估计场景距离 | Depth Anything 3 的合适变体作几何先验 | 需要可靠米制精度时，添加尺度约束、RGB-D 或标定双目。 |

## 4. 实际使用时，哪些问题最值得检查？

### 4.1 部署前的六项检查

1. **输入前提：** 模型要求 RGB、RGB-D、双目、CAD、参考图像，还是文本/框/Mask？对应资源是否真的可用？
2. **坐标和尺度：** 深度是不是以米为单位？Mask 与深度是否对齐？位姿位于相机系还是机器人基座系？相机外参是否已另行标定？
3. **时序和身份：** 目标是否跨帧保持同一个 ID？有无遮挡时如何重定位？时间戳是采集时刻还是推理完成时刻？
4. **失败模式：** 透明/反光物体、弱纹理、对称形状、快速运动和手部遮挡，分别影响哪一个模块？
5. **时延预算：** 端到端延迟包括图像采集、模型前向、传输与控制；论文 FPS 不等于部署控制频率。
6. **许可和接口：** 查官方权重、代码与商业使用许可；核实输入格式、输出定义、GPU 显存以及是否真的支持所需工作模式。

### 4.2 不应由视觉大模型独自承担的事情

**高置信 Mask 不代表准确位姿；准确位姿不代表接触成功。** 灵巧手抓取、精密插装与旋转工具时，往往还需要手指关节状态、接触/力觉、本体状态和主动纠错。物体被遮挡、掉落或重定位失败时，应允许“暂停动作—重新观察—重新初始化”，而不是把过期位姿继续传给控制器。

**把模型能力与系统能力分开评估。** 官方论文说明模型能做什么；机器人系统是否可用还取决于传感器质量、延迟、外参、对象几何和下游控制。对无法从图像唯一观察的对称角度，不能仅靠换更大的模型解决。

### 4.3 选型速查：记住这七句话

- **找目标且有语言描述 → SAM 3；** 只要开放词汇边界框 → Grounding DINO。
- **已知目标、想连续得到 Mask → SAM 2；** 多目标视频也可考察 SAM 3.1。
- **已有可信 RGB-D → 直接用现成深度；** 不必为了使用基础模型而再估计一遍。
- **有标定同步双目、要深度 → FoundationStereo；** 紧张的时延预算下考察 Fast-FoundationStereo。
- **单目 RGB、要粗略几何 → Depth Anything 3；** 先核对 checkpoint 的尺度属性。
- **有刚体物体的 CAD/参考图像、要 6D 位姿 → FoundationPose。**
- **缺 CAD、要候选物体形状 → SAM 3D Objects；** 人体三维重建则看 SAM 3D Body。
